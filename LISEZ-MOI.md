# LISEZ-MOI · prêt en 5 minutes

Le vault d'équipe de **Camille, Oumar et Alescis** pour le projet fil rouge (projet collectif). Pour l'instant : **BLOC 1 · Conception**. Les BLOCs 2 et 3 s'ajouteront avec le modèle « Nouveau bloc ».

## 1. Installer (une seule fois)
1. **Obsidian** : https://obsidian.md/download
2. **Git** : https://git-scm.com/downloads (sur Mac, il s'installe tout seul la première fois qu'on tape `git` dans le Terminal)
3. **Récupérer le vault** : dans un terminal
   ```
   git clone https://github.com/galsen-76/CDA-BLOC.git
   ```
   (il faut avoir été ajouté comme collaborateur du dépôt sur GitHub, et se connecter quand Git le demande)
4. Dans Obsidian : **Ouvrir un dossier comme coffre** → choisir le dossier `CDA-BLOC` → **Faire confiance à l'auteur et activer les plugins**.

## 2. Activer les 3 plugins
**Paramètres → Plugins communautaires → Parcourir**, installer puis activer :
- **Dataview** (les tableaux de bord)
- **Templater** (les modèles de notes)
- **Obsidian Git** (la synchronisation)

Les réglages de Dataview et Templater sont déjà dans le vault. Pour **Obsidian Git**, régler une fois (Paramètres → Obsidian Git) :
- *Auto commit-and-sync interval* : **10** (minutes)
- *Pull on startup* : **activé**
- *Pull before push* : **activé**

Le style (extrait CSS **bloc-workspace**) est déjà activé. Sinon : Paramètres → Apparence → Extraits CSS. Thème **sombre** conseillé.

## 3. Commencer
1. Ouvrir **[[Accueil]]** : l'avancement de toute l'équipe.
2. Lire **[[Règles d'équipe]]** (2 min) : qui écrit où, pour zéro conflit.
3. Lire **[[BLOC 1 - Vue d'ensemble]]** puis **[[Répartition et plan de travail]]**.
4. Ouvrir **son espace** : [[Camille]] · [[Oumar]] · [[Alescis]].

## Comment c'est rangé
```
00 - Accueil/          tableau de bord, calendrier, équipe, règles
01 - Membres/          un dossier par personne : SEULE la personne y écrit
02 - Réunions/         un fichier par réunion
03 - Décisions/        un fichier par décision
10 - BLOC 1 - Conception/
    BLOC 1 - Vue d'ensemble       contexte, étapes, avancement, checklist
    Répartition et plan de travail
    Sujet/                         le sujet résumé, où trouver quoi
    Dossier/                       1 fichier = 1 section du dossier (1 propriétaire)
                                   + la note d'assemblage → export PDF
    Soutenance/                    les slides (reprennent les sections)
    Tâches/  Diagrammes/  Rendu/
    Ressources BLOC 1
90 - Outils/           modèles et script des tableaux de bord
```

## Le principe en une phrase
**On écrit une fois, dans sa section : le dossier PDF et les slides se construisent tout seuls à partir des sections.**
